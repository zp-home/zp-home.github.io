Architecture Open Source Research

用证据驱动的方式检索、比较和记录可复用开源项目，为系统架构和技术选型提供可追溯依据。

2026/08/12触发：架构设计 / 技术选型 / 开源调研
Repository

这项 Skill 关注“为什么选”，而不只是“搜到了什么”。它要求把仓库身份、许可证、维护状态、依赖边界和可复用位置写进同一份研究记录。

工作流

  1. 把系统目标拆成可检索的能力边界。
  2. 从官方仓库和包注册表交叉确认项目身份。
  3. 比较许可证、活跃度、实现深度与集成代价。
  4. 明确采用、参考或拒绝，并记录证据链接。
  5. 把调研结果转换为分阶段实现计划。
